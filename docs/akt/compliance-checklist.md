# AKT SBA Quality Checklist (QA Tool)

Use this as:

- a **pre-release checklist** for new questions
- an **automated validation rubric** (e.g. in scripts or admin)
- a **reviewer scorecard** when auditing questions

---

## AKT SBA Quality Checklist

### Structure

- [ ] **Clear task** being asked (e.g. best next step, first-line treatment, action to avoid)
- [ ] **Adequate but not excessive** clinical detail
- [ ] **Grammar and terminology** correct (UK English, primary care)

### Reasoning

- [ ] Requires **applied decision-making** (not pure recall)
- [ ] **Double-barrelled reasoning** (if present) is fair
- [ ] **No critical missing information** that makes the question unfair

### Single Best Answer

- [ ] **One option** is clearly best
- [ ] **Distractors** are plausible but inferior
- [ ] **No equally correct** options

### Difficulty

- [ ] **AKT-level** (not recall-based)
- [ ] Tests **prioritisation**, **safety**, or **sequencing**

### Explanation

- [ ] **Correct answer** justified
- [ ] **All distractors** explained (why not best)
- [ ] Written **clearly** for GP trainees

### Guidelines

- [ ] **UK-based references** included where appropriate
- [ ] **Guidance supports** the answer given
